Sobre este registro. Los pedidos se guardan en el navegador de este equipo, no en un servidor: no se comparten con otras computadoras ni con otros navegadores, y se pierden si se borran los datos de navegación. Para consolidar la información de varias máquinas usá Copia de seguridad e Importar. La contraseña evita el acceso casual, pero no es un control de seguridad real: cualquiera que abra el código de la página puede verla. Si necesitan un registro único y compartido para toda el Área, hace falta una base de datos o una planilla en línea.
